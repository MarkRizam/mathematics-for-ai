# Limitations
Small synthetic dense real arrays only. LU rejects numerically singular pivots; QR requires full column rank and does not reorthogonalize. No complex, sparse or batched inputs. Eigen/SVD use NumPy reference solvers. Scalar reverse mode supports a limited operation set and recursively traverses graphs; not a tensor engine. Numerical differentiation assumes smooth scalar objectives; rounding and cancellation limit accuracy. Optimizers use fixed default coefficients and no line search; equal steps do not imply equal compute. Three seeds are not statistical evidence of general performance. No hardware runtime or memory benchmarks, Docker verification, or external data. Hosted CI and wider audit are pending. References are links, not redistributed copies.
